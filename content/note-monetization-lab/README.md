# note収益化ラボ

FX Quest Guildとは別アカウントで運用する、note収益化・コンテンツ販売の検証ブランドです。

## 運用原則

- FX Quest Guildの投稿台帳・ブラウザプロファイル・CTAを共有しない
- 無料記事は悩みの整理と最初の改善、有料記事は手順・テンプレート・記録方法を提供する
- タイトルと1枚目画像は別の役割にする
- 売上・販売数を確認できない場合は推測で補わない
- 生成後は人がタイトル、画像、事実関係、価格、有料部分を承認する

## 初期投稿配分

- 無料記事: 週3本
- 有料記事: 週1本
- 売れ筋分析: 週1本

## ディレクトリ

- `drafts/`: 生成済みMarkdown
- `thumbnails/`: 1枚目画像
- `posted-ledger.json`: 専用投稿台帳
- `latest.json`: 最新生成結果
- `experiments.json`: タイトル・画像・価格の検証記録
